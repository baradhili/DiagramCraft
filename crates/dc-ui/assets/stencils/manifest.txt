# Built-in stencil catalog manifest (GitHub #87, expanded per the #85 follow-up 2026-10-27).

# One line per catalog entry:
#   slug | category | display title | source file in Visio Content/1033
#
# Coverage: every shipped US-units stencil (187 entries) except:
#   - *_VISIO2013_U.VSSX backward-compat variants (21 files; the modern set ships)
#   - duplicate display titles within a category — the richer stencil wins
#     (most masters, then largest file): LEGEND_U.VSSX → LGND, COMPS_U.VSSX → COMPME, NETLME_U.VSSX → NETLOC, NETSME_U.VSSX → NETSYM, SERVME_U.VSSX → SERVER
#   - DVCALL_U.VSSX "Data Graphics" (all its masters are hidden/special —
#     data-graphic definitions, not droppable shapes)
#   - SDCALL_U.VSSX, the auto-open callouts companion (its menu entry is the richer
#     CALOUT "Callouts"; sdcall stays an auto-open default for #105)
#
# Categories follow the observed Visio 2016 More Shapes taxonomy (owner screenshots);
# the per-stencil assignment is our curation over each stencil's dc:title. Editing this
# file and re-running extract-stencils.rs regenerates the catalog deterministically.

# repository as built-in stencil assets under the scoped owner exception of 2026-10-25
